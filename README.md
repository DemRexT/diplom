# Суть — учебный помощник

Прототип бакалаврского диплома на Python 3.12 / FastAPI. Загруженный учебный текст преобразуется через API нейросети в конспект, ключевые мысли, карточки и тест с обратной связью. Интерфейс на HTML/CSS/JavaScript.

## Запуск

```bash
cd /workspace/diplom
python -m venv .venv
.venv/bin/pip install -r requirements.txt
export YANDEX_API_KEY='ваш ключ' # задавайте безопасно, не сохраняйте в Git
export YANDEX_FOLDER_ID='идентификатор каталога'
export YANDEX_MODEL=yandexgpt/latest
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Используется нативный Foundation Models API YandexGPT. Для сервисного аккаунта нужна роль `ai.languageModels.user` в каталоге Yandex Cloud, включённый биллинг и API-ключ с разрешением на вызов моделей. Ключ используется только сервером. Без ключа и ID каталога сайт открывается, обработка сообщает о недоступности. `.env.example` описывает переменные; автоматического чтения `.env` нет.

На Windows создайте окружение командой `py -3.12 -m venv .venv`, используйте `.venv\Scripts\python -m pip install -r requirements.txt` и `.venv\Scripts\python -m uvicorn app.main:app --reload`. Переменные в PowerShell задаются через `$env:YANDEX_API_KEY` и `$env:YANDEX_FOLDER_ID`.

Проверки: `.venv/bin/python -m pytest -q`. API-документация: `/docs`, состояние: `/health`.

## Ограничения прототипа

PDF с текстовым слоем, DOCX (абзацы и таблицы), TXT UTF-8; до 10 МБ, 200 страниц PDF и 45 000 символов. OCR не включён. Документы и результаты не сохраняются; результат существует в памяти браузера до перезагрузки. Текст передаётся внешнему провайдеру после отправки формы. Ответ нейросети проверяется по структуре, но достоверность требует сравнения с источником. Тест предназначен для самопроверки, правильные ответы доступны браузеру.

Перед публичным размещением необходимы аутентификация, ограничение частоты/параллелизма запросов и затрат API, ограничение тела запроса на reverse proxy, изоляция парсеров документов и политика обработки данных. Сейчас это локальный прототип без этих мер.

## Развитие диплома

Хранение истории и пользователей (PostgreSQL), ссылки на страницы источника, оценка качества конспектов и вопросов на наборе методичек, сравнение моделей, повторение карточек с учётом ошибок. Основной исследовательский вопрос: насколько автоматически созданные конспекты и задания помогают усвоить материал без потери ключевых фактов.
